## Attribution

Attribution is required. Font Awesome ships a copyright comment inside each
downloaded SVG, and that embedded comment is sufficient attribution on its
own — so **do not strip it**. `linktree.svg` carries:

```
<!--!Font Awesome Free 7.3.1 by @fontawesome - https://fontawesome.com
License - https://fontawesome.com/license/free
Copyright 2026 Fonticons, Inc.-->
```

Because this project inlines the SVG via `?raw` and `set:html` in
`LocalIcon.astro`, the comment ships to visitors in the rendered markup too,
which satisfies the attribution requirement for the site as a whole.

If the icon is ever moved to an `<img src>`, a CSS `url()`, or stripped down to
just the `<path>`, the comment stops reaching users — add a visible credit on
the site in that case.
